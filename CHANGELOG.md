# Changelog

## v1.0.0 - 2026-09-07

- Initial public release.
- Added a fully offline browser app for converting mixed Simplified, Traditional, and variant Chinese text into Chinese Mainland standard Traditional forms.
- Added an OpenCC-style deterministic conversion pipeline with phrase dictionaries first and character dictionaries as fallback.
- Added automatic Chinese/English UI language switching based on browser locale.
- Added text file import, output copy, and output download.
